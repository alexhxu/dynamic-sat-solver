Dynamic Load Balancing for Parallel SAT Solving

Alex Xu and Alma Zhong

Summary

We will implement the divide-and-conquer parallel SAT architecture described by Le Frioux et al., using MiniSat as the sequential solving engine on shared-memory multicore CPUs (the GHC machines, and PSC if time permits). Our focus is the parallel systems problem of dynamically distributing irregular search subtrees across worker threads. We will compare static partitioning with dynamic work redistribution and evaluate speedup, idle time, scheduling overhead, and wasted speculative work.

As of November 19 the repo builds a sequential solver. MiniSat 2.2 is vendored and compiles with AppleClang. Cube::divide splits a guiding path, a worker solves under assumptions, and requestInterrupt() stops that solve from another thread (covered by the pigeonhole test). The master solves one cube on one worker and records wall time. Static partitioning, dynamic division, both division heuristics, clause sharing, and portfolio mode are parsed and then rejected. The only CNFs in the tree are the two smoke instances. Static partitioning and benchmark selection, which the proposal had placed in November 9–22, are the work of November 19–22.
